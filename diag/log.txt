Konceptuálny dátový model API vyzerá takto: Portál (a teda aj API) poskytuje informácie o rozpočte: štátnej správy (podľa zákona č. 211/2000): Pre štátnu správu sú dostupné informácie o rozpočtoch kapitol, ich podriadených organizácií a o rozpočtoch ostatných subjektoch verejnej správy (s podriadenými organizáciami). samosprávy (dáta z finančných výkazov): Pre samosprávu sú dostupné informácie za jednotlivé VÚC a ich podriadené organizácie (školy a pod.), pre obce sú k dispozícii informácie za celú obec a aj jednotlivo za jej podriadené organizácie. Údaje sú zverejňované pod licenciou CC0. Údaje sú k dispozícii pre subjekty štátneho rozpočtu, ostatných subjektov verejenej správy od roku 2006 v granularite ročných sumárov. Pre roky R až R - 2 sú k dispozícii aj podrobnejšie mesačné sumáre, pričom z kapacitných dôvodov tieto podrobné údaje prestávajú byť po dvoch rokoch dostupné. R je rok ostatnej (najčerstvejšej) uzávierky. Typicky teda napr. medzi januárom a marcom 2016 je najčerstvejšou uzávierkou tá za rok 2014 a teda podrobné údaje sú k dispozícii pre roku 2013 a 2014. V marci zvykne byť hotová uzávierka za predchádzajúci rok a teda po marci 2016 sú podrobné údaje k dispozícii pre roky 2014 a 2015. Údaje v zásade iba pribúdajú, a to vždy po uzávierkach. API teda neposkytuje zmenové informácie. Pre nové údaje stačí robiť dopyt, t.j. napr. ak už je marec, môžeme si pýtať údaje za predchádzajúci rok. V prípade chyby (404 Not Found) - zrejme nastalo zdržanie v spracovaní rozpočtu - treba počkať a opakovať dopyt znova. Služby API možno rozdeliť do dvoch skupín: údaje o rozpočte číselníky použité v rozpočtoch Všeobecné informácie API je realizované štýlom RESTfull a teda všetky príklady v tejto dokumentácii možno "volať" či už priamo kliknutím na linku alebo napr. pomocou rôznych nástrojov (napr. curl), napr.: curl https://rozpocet.sk/api/vs/ciselnik/organizacie/0 Ďalšie informácie: bodka oddeľuje desatinné miesta v číslach všetky sumy sú v Euro dátumy sú formátované podľa ISO 8601, t.j. vo forme RRRR-MM-DD Formát dopytov Všetky dopyty API sú popísané schémou URL, napr.: /api/{segmentVS}/ciselnik/organizacie/{?kodOrganizacie} Povinné parametre sú bez otáznika (napr. '{mandatory}'), nepovinné parametre s otáznikom (napr. '{?optional}'). Bežne používané parametre vo väčšine dopytov sú: segmentVS - štátny rozpočet a ostatné subjekty verejnej správy ('vs'), subjekty samosprávy ('sam') kodOrganizacie - kód organizácie, typicky IČO, sú však aj "špeciálne hodnoty": 0 - štátny rozpočet 1 - štátne fondy 2 - Verejné zdravotné poistenie 120 - Ostatné subjekty verejnej správy 830 - Dopravné podniky rok - rok, pre ktorý žiadame údaje mesiac - mesiac, pre ktorý žiadame údaje Formát odpovede API poskytuje odpovede v dvoch formátoch: JSON (by default alebo na požiadanie) CSV (na požiadanie) Formát JSON API poskytuje odpovede vo formáte JSON "by default", alebo si tento formát možno vyžiadať explicitne použitím parametra '?format=json' v dopyte. Štruktúra odpovede vo formáte JSON vyzerá vo všeobecnosti takto: {"payload":[ {nazov_stlpca1:hodnota_stlpca1,nazov_stlpca2:hodnota_stlpca2, ...}, ... ],“length“:...,“success“:true} Príklad použitia: curl https://rozpocet.sk/api/vs/ciselnik/organizacie/0?format=json Formát CSV API poskytuje odpovede tiež vo formáte CSV a tento formát možno vyžiadať explicitne použitím parametra '?format=csv' v dopyte. Štruktúra odpovede vo formáte CSV vyzerá vo všeobecnosti takto: nazov_stlpca1,nazov_stlpca 2,... hodnota_stlpca1,hodnota_stlpca 2,... ...
